# Go Tutorial API (Gin + MongoDB)

A minimal REST-style API built with Go and Gin, demonstrating:
- Connecting to MongoDB
- Basic routing with path params and JSON parsing
- Simple model structure for a `User`

## Tech Stack

- Go (module: `myapp`, go version: `1.25.3` per `go.mod`)
- Gin (`github.com/gin-gonic/gin`)
- MongoDB Go Driver (`go.mongodb.org/mongo-driver`)
- Dotenv (`github.com/joho/godotenv`)
